# Accounts Payable & Spend Analysis Dashboard

## Project Overview
This project analyzes accounts payable, vendor performance, payment trends, overdue invoices, and discount utilization using Microsoft Power BI.

## Business Objectives
- Monitor total invoiced and paid amounts.
- Analyze overdue liabilities and invoice aging.
- Evaluate vendor payment performance.
- Track discounts captured and lost.
- Identify spending patterns across categories.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel (data source)

## Key Performance Indicators
- Total Invoice Amount: 24.67M
- Total Amount Paid: 18.89M
- Overdue Amount: 3.10M
- On-Time Payment: 60.37%
- Discount Captured: 47%
- Discount Lost: 53%
- Average Days to Pay: 37

## Dashboard Pages

### 1. Executive Overview
- Financial KPIs
- Monthly payment trends
- Category-wise spending
- Overdue aging analysis

### 2. Vendor Performance
- Number of invoices by vendor
- Amount paid by vendor
- Average days to pay
- Overdue amount
- Discount captured and lost

## Key Insights
- Payments and spending vary across months.
- Logistics & Freight is the largest spending category in the current dataset.
- The 90+ days overdue bucket contains a substantial share of overdue balances.
- Discount performance varies across vendors.

## Recommendations
- Investigate long-overdue invoices.
- Review vendors with high overdue balances.
- Identify opportunities to capture eligible early-payment discounts.
- Monitor payment timeliness and spending trends.
